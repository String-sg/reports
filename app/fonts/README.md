# Brand font files

These unmodified font files come from `String-sg/string-brand-guide`, `5. Fonts/`:
Montserrat and Space Grotesk, regular/medium/semibold/bold. The adjacent OFL texts
are from the official google/fonts repository, ofl/montserrat/OFL.txt and
ofl/spacegrotesk/OFL.txt. next/font/local preserves the existing family variables
and serves the files from the built deployment without a Google build-time fetch.
